# AI 브리핑 프롬프트

구현: [api/briefing.ts](../../../api/briefing.ts). `buildPrompt()`가 프롬프트를 만들고, Gemini로 **스트리밍**(text/plain chunked) 응답.

- **모델:** `gemini-2.5-flash` (`@google/genai`, `GEMINI_API_KEY` 필요).
- **입력:** 기사 제목+출처 목록 **상위 50건만** (`articles.slice(0, 50)`). 본문 없이 **제목만** 근거.

## 고정 출력 형식 (마크다운 헤더 유지 필수)
```
## 핵심 요약
## 주요 흐름
### 글로벌 빅테크
### 국내 AX
### 정책·사회
## 지켜볼 단서
## 놓치지 말 기사   (1~3위, **제목** — 출처)
```
프론트엔드가 이 `##`/`###` 헤더를 파싱하므로 **헤더 텍스트·구조를 바꾸면 렌더링이 깨진다.** 형식 변경 시 [src/components/AiBriefing.tsx](../../../src/components/AiBriefing.tsx) 파서도 함께 확인.

## 환각·노출 방지 규칙 (수정 시 절대 약화시키지 말 것)
이 프롬프트의 핵심은 "제목에 없는 건 만들지 않기"다. PR #25는 **지시문이 출력에 그대로 노출되던 버그** 수정이었음 — 같은 류 실수를 반복하지 말 것.
1. 기사 제목에 없는 사실은 추론·추가 금지.
2. 회사명·제품명·날짜는 제목에 명시된 것만.
3. "지켜볼 단서"는 제목에 명시된 일정·예고만, 없으면 `오늘 기사에 명시된 일정 없음` 한 줄.
4. 카테고리에 해당 기사 없으면 `해당 기사 없음` 한 줄.
5. **작성 지침(대괄호 `[]` 안내문, 괄호 안 설명)은 출력에 포함하지 말고 실제 내용만** — 안내문은 반드시 대괄호로 감싸 모델이 복사하지 않게 함.

## 수정 가이드
- 형식 칸을 추가/변경하면: ① 프롬프트의 형식 블록, ② 규칙 번호, ③ 프론트 파서 3곳을 함께 맞출 것.
- 새 안내문은 평문이 아니라 **대괄호 안**에 넣어 출력 누출을 막는다.
